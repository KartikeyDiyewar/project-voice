How Wispr Flow Works: Complete Visual Breakdown

Wispr Flow is not just speech-to-text. The magic comes from speed (<500ms total), AI post-processing (removing filler words and formatting), and instant system-wide typing injection into any focused window.

🎯 Bring Your Own Key (BYOK) ⚡ Sub-500ms End-to-End Latency 🔒 100% Privacy (Zero intermediate servers) 💻 Windows Native First -> Mobile Next
The 5-Step Execution Pipeline The Core Engine
1
Global Hotkey
Windows Win32 Hook
  • Runs silently in the background using pynput or Win32 API.
  • No focus stealing: You stay in Slack, Chrome, or VSCode.
  • Key Down: Instantly starts microphone recording stream.
  • Key Up: Stops recording and fires transcription immediately.
💡 Asaan Bhasha Mein: Aap CapsLock ya Alt+Space dabakar rakhenge, tabhi mic chalu hoga. Jaise hi chodenge, pipeline start ho jayegi!
2
Audio Buffer
In-Memory RAM Streaming
  • Captured using sounddevice at 16kHz Mono (Whisper's sweet spot).
  • In-Memory RAM (io.BytesIO): We do NOT write to slow SSD/hard drive files.
  • Packed into pure WAV bytes in under 5 milliseconds.
💡 Asaan Bhasha Mein: Audio ko hard drive par save karne ki zaroorat nahi hai. RAM me direct byte stream banta hai, isse speed rocket jaisi hoti hai.
3
Fast Speech-to-Text
Groq Whisper API
  • Sends WAV bytes to whisper-large-v3-turbo.
  • Groq LPU Speed: Transcribes a 10-second voice note in ~180-250ms!
  • BYOK: Direct call to Groq using user's key.
  • Output: Raw text with pauses and filler words.
💡 Asaan Bhasha Mein: Whisper model aapki aawaz ko text banata hai. Groq itna fast hai ki aawaz bolte hi 200 millisecond me text aa jata hai.
4
AI Formatting LLM
Wispr Flow's Secret Sauce
  • Raw speech has "umm", "like", stuttering, and zero punctuation.
  • Passed through Llama 3.3 70B or GPT-4o-mini.
  • Prompt cleans up fillers, corrects grammar, and formats into crisp sentences.
  • Adapts tone: Email vs Code vs Chat!
💡 Asaan Bhasha Mein: Yahi Wispr Flow ka sabse bada secret hai! Ye aapke "umm, ahh, matlab, you know" hata deta hai aur text ko ekdum professional bana deta hai.
5
OS Auto-Paste
Clipboard & Virtual Keystroke
  • Formatted text is pushed to Windows clipboard.
  • App fires virtual Ctrl + V key event.
  • Because focus was never lost, text pastes right into your cursor position!
  • Total round-trip time: ~450 milliseconds.
💡 Asaan Bhasha Mein: Clean text seedha clipboard me jaata hai aur system automatically Ctrl+V press karta hai. Aapko pata bhi nahi chalta aur likh jaata hai!

🔑 Bring Your Own Key (BYOK) Explained

Traditional dictation apps charge $15–$30/month. With BYOK, the user brings their own API key (Groq or OpenAI):

Feature Wispr Flow SaaS ($15/mo) Our BYOK App ($0/mo)
Monthly Cost $15 - $20 / month $0 (Groq has 14,400 free requests/day)
Privacy Passes through company servers 100% Local & Direct to API
Custom Prompts Locked presets You control the LLM prompt
Latency ~500ms ~400ms (Direct Groq LPU)
📱 What about Mobile later?
Windows allows background global keyboard hooks + Ctrl+V. On mobile (iOS/Android), security sandboxes block this. So on mobile, Wispr Flow is implemented as an IME Keyboard Extension (like Gboard) with a custom microphone button!

🚀 Our Step-by-Step Learning Roadmap

You don't have to code everything at once. We build 5 tiny, readable scripts where you understand every line:

1

01_mic_test.py Record & Save WAV

Learn how Python talks to your microphone, captures raw PCM sound waves, and calculates decibel volume levels.

2

02_whisper_stt.py Cloud Transcription

Connect your Groq/OpenAI key. Send the recorded audio in RAM directly to Whisper and print the raw text response.

3

03_llm_cleaner.py The Intelligence Prompt

Pass the raw transcript through Llama 3.3. Test prompt engineering to eliminate "umms" and format bullet points.

4

04_global_dictate.py Hotkey & Auto-Paste

Hook global keypresses (e.g. CapsLock). Open Notepad, hold CapsLock, talk, release, and watch it type automatically!

5

05_floating_ui.py Sleek Floating Pill

Add a beautiful macOS/Windows style minimal floating overlay pill that reacts to your voice with a glowing wave.
